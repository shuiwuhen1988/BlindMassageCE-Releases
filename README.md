# 盲按继教

本仓库只用于公开发布盲按继教 Windows 安装包，不包含源代码。

## 最新版本

- 版本：`2.2.1`
- 系统：Windows 10 build 16299 及以上
- 架构：自动适配 `win-x86` 与 `win-x64`
- 安装包：`BlindMassageCE-2.2.1-win-universal-Setup.exe`
- 下载位置：本仓库 Releases 中的 `v2.2.1`

## 本版修复

- 五个原生页签完整可见，可直接使用鼠标、键盘和读屏操作。
- 修正部分 Windows 10 系统播放视频无声相关的音频设备参数问题。
- 修复播放器关闭期间可能出现的系统错误框。
- 学习记录打开课程时只读同步平台断点，支持同一账号跨电脑续播。
