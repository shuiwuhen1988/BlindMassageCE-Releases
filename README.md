# 盲按继教

本仓库只用于公开发布盲按继教 Windows 安装包，不包含源代码。

## 最新版本

- 版本：`2.2.4`
- 系统：Windows 10 build 16299 及以上
- 架构：自动适配 `win-x86` 与 `win-x64`
- 安装包：`2.2.4.exe`
- 下载位置：本仓库 Releases 中的 `v2.2.4`

## 本版改进

- 修复“更多功能 → 密码修改”提交无效的问题，密码修改现在能正确提交到平台。
- 修复播放器静音偶尔自动取消的问题。
- 修复极少数系统播放视频无声音的问题，新增音频输出自动回退。
