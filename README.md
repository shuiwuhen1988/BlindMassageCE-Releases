# 盲按继教

本仓库只用于公开发布盲按继教 Windows 安装包，不包含源代码。

## 最新版本

- 版本：`2.2.3`
- 系统：Windows 10 build 16299 及以上
- 架构：自动适配 `win-x86` 与 `win-x64`
- 安装包：`2.2.3.exe`
- 下载位置：本仓库 Releases 中的 `v2.2.3`

## 本版改进

- 播放器新增“播放清晰度”选择，选项与平台一致（流畅/标清/高清/超清/全高清/2K/4K/原画），切换后立即生效并保持播放位置、倍速与音量。
- 默认清晰度按平台 `video_definition` 自动匹配，进入清晰度组合框即停在平台默认档。
- 修复 NVDA 在主界面页签间切换时重复播报“功能选项卡”的问题，现在只读页签自身名称。
