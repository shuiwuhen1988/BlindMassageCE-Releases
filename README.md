# 盲按继教

本仓库只用于公开发布盲按继教 Windows 安装包，不包含源代码。

## 最新版本

- 版本：`2.2.5`
- 系统：Windows 10 build 16299 及以上
- 架构：自动适配 `win-x86` 与 `win-x64`
- 安装包：`2.2.5.exe`
- 下载位置：本仓库 Releases 中的 `v2.2.5`

## 本版改进

- 修复播放器设置不记忆“输出模式”：保存后再次打开设置，光标自动停在用户上次选择的模式（自动 / DirectSound / WASAPI / waveOut）。
- 修复 waveOut 输出在 2 倍速下声音卡顿：为 waveOut 固定走 16 位 PCM 兼容路径（仅影响 waveOut）。
- 保留 2.2.4 修复：密码修改按网站格式提交、静音不再被输出切换重置、极少数系统无声音的音频输出自动回退链。
