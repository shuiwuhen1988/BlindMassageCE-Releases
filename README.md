# 盲按继教

本仓库只用于公开发布盲按继教 Windows 安装包，不包含源代码。

## 最新版本

- 版本：`2.2.5`
- 系统：Windows 10 build 16299 及以上
- 架构：自动适配 `win-x86` 与 `win-x64`
- 安装包：`2.2.5.exe`
- 下载位置：本仓库 Releases 中的 `v2.2.5`

## 本版改进

- 播放器设置记忆“输出模式”：保存后再次打开，光标自动停在用户上次选择的模式。
- 播放器新增“选择讲”列表（标准 ListBox），上下光标选择任意视频，回车播放；保留 PageUp/PageDown 切换上一讲/下一讲。
- 退出程序时注销会话并行并限时，避免平台服务器拥堵时关闭卡住。
- 保留 2.2.4 修复：密码修改、静音、无声音回退链等。
