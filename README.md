# 盲按继教

本仓库只用于公开发布盲按继教 Windows 安装包，不包含源代码。

## 最新版本

- 版本：`2.2.2`
- 系统：Windows 10 build 16299 及以上
- 架构：自动适配 `win-x86` 与 `win-x64`
- 安装包：`BlindMassageCE-2.2.2-win-universal-Setup.exe`
- 下载位置：本仓库 Releases 中的 `v2.2.2`

## 本版修复

- 状态栏显示并向读屏暴露当前账号名称，不再只读固定的“当前账号、操作状态”。
- 在账号列表按回车切换账号后，立即朗读“已切换到当前账号：姓名。”，焦点仍保留在账号列表。
- 全局界面字体调整为 `Segoe UI 12` 磅，提升列表、页签、按钮、状态栏和对话框的可读性。
- 主动播报使用标准 UIA/MSAA 通知，不包含争渡或 NVDA 语音接口文件。
